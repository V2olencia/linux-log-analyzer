# Segurança e privacidade

Use apenas logs próprios, de laboratório ou devidamente anonimizados. Dados de autenticação podem identificar pessoas e sistemas.

Antes de abrir uma issue, remova nomes de usuário, endereços IP reais, nomes de host, caminhos pessoais, tokens e qualquer outro segredo. O projeto não transmite dados e deve ser executado localmente.
